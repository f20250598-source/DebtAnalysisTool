# DebtAnalysisTool
This code is a tool that:
1)Analyzes debt trends over multiple fiscal years
2)Compares against sector-specific benchmarks (15 industries)
3)Calculates actual peer averages from top 10 sector companies
4)Provides interest coverage ratio (EBITDA / Interest Expense)
5)Identifies high-cost borrowings that need refinancing
6)Shows debt composition changes year-over-year
